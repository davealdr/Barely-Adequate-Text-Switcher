Instructions

Once downloaded Put the BATS folder wherever you like. Do not remove any files or folders from the BATS folder, If you wish for the .EXE to be accessible from a more convenient place you can create a shortcut for it.

In [OBS](https://github.com/obsproject/obs-studio) Use a Text (GDI+) Source, Go to Properties and select Read from file. Click browse, Navigate to wherever your BATS folder is, Go in the folder Switcher Files and select Text Switcher.txt.

In BATS put your lines of text in the text box, Each line will be shown in sequence. Use the Set as default text button to do exactly that, It also saves the number of seconds selected as well as the state of the random sequence button.
